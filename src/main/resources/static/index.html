Streamlined Campus Pipeline

How CampusFind Works

A secure, non-automated 4-step recovery process engineered to protect your personal property and privacy.

1. Report Details

Submit descriptive details, category, date, and safe campus landmark where you misplaced or discovered the item.

2. Smart Matching

Our multi-factor matching engine calculates similarity scores and alerts both reporters when confidence exceeds 60%.

3. Ownership Audit

Claimants furnish private unlisted details (serial numbers, internal contents). Campus administrators verify legitimacy.

4. Safe Handover

Physical handover takes place at the Campus Security Desk with verified ID signoff. Status updates to Returned in real-time.

University Project

Smart Lost and Found Management System

Designed and engineered specifically for university campuses, CampusFind eliminates manual circulars and fragmented lost item announcements with a centralized, data-driven system.

System Highlights

  • Zero Sensitive Contact Leakage: Phone numbers and ID proofs are masked from public view. Only secure campus collection points are visible publicly.
  • Intelligent Matching Algorithm: Automated similarity scoring comparing category, text tokens, date deltas, and landmark proximity.
  • Multi-tier Verification Pipeline: Mandatory non-public proof inspection by campus administrators before handovers are approved.
  • Full MySQL & Spring Boot Architecture: High-performance Spring Boot 3.x REST API layer paired with persistent relational MySQL storage.
